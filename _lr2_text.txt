2.1 Общие сведения о диалогах

Диалоги – это всплывающие окна, которые появляются поверх основного интерфейса приложения для взаимодействия с пользователем. Они позволяют передать важную информацию, запросить подтверждение, данные или предложить выбор действий, не выводя пользователя из текущего контекста приложения.
Основные характеристики диалогов:
1. Всплывающее окно: диалоги временно перекрывают интерфейс приложения, фокусируя внимание пользователя на конкретной задаче или информации.
2. Взаимодействие: они используются для получения от пользователя ответа, подтверждения или ввода данных, а также для отображения важных сообщений.
3. Ограниченность контекста: диалоги обычно ограничены одной задачей – например, подтверждение действия, выбор даты или отображение ошибки.
Типы диалогов:
1. Информационные (Alert Dialog): уведомляют пользователя о важной информации или запросе подтверждения. Примером может служить подтверждение удаления объекта, сообщение об ошибке или предупреждение.
2. Выбор даты/времени (Date/Time Picker Dialog): позволяют пользователю выбрать конкретную дату или время с помощью удобного интерфейса.
3. Пользовательские диалоги (Custom Dialog): это диалоги, которые можно настроить под конкретные требования интерфейса приложения. Они могут включать любые пользовательские элементы управления, такие как текстовые поля, кнопки, изображения и другие компоненты.
Цели использования диалогов:
- Оповещение пользователя о важном событии или состоянии системы (например, успешная отправка данных).
- Запрос подтверждения действий (например, диалог с подтверждением удаления данных).
- Ввод данных (например, текст, даты, выбор из списка).
- Предоставление пользователю выбора между несколькими вариантами.
- Отображение подробной информации или инструкции.
Диалоги играют ключевую роль в улучшении взаимодействия пользователя с приложением, делая его более интуитивным и управляемым.

В Flutter аналогичная функциональность для создания диалогов реализуется с помощью «showDialog». Вот как можно перевести указанный вами код для Android на Flutter:

1. showDialog – это метод, который отображает диалоговое окно поверх экрана. Оно принимает «context» и «builder», который возвращает диалог.
2. AlertDialog – это стандартный диалог в Flutter, который можно настроить с помощью заголовка («title»), содержания («content»), иконки и действий (`actions`).
3. Кнопки в диалоге добавляются через «actions», где каждая кнопка представляет собой «TextButton». Они определяют действие, которое выполняется при нажатии.
Этот код показывает диалог с тремя кнопками: «Да», «Нет» и «Отмена», и закрывает приложение или отменяет действие в зависимости от выбора пользователя.

В Flutter, как и в Android, «AlertDialog» позволяет отображать различные варианты содержимого, включая списки. Давайте создадим глобальный список элементов для вывода их в диалоге и настроим диалог с обработкой нажатий на элементы.
Сначала создадим список элементов:

void showCustomDialog(BuildContext context) {

List&lt;String&gt; items = ["Пункт 1", "Пункт 2", "Пункт 3"];

  showDialog(
    context: context,
    builder: (BuildContext context) {
      return AlertDialog(
        title: Text('Выберите элемент'),
        content: SingleChildScrollView(
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: items.map((String item) {
              return ListTile(
                title: Text(item),
                onTap: () {
                  Navigator.of(context).pop();
            ScaffoldMessenger.of(context).showSnackBar(
   SnackBar(content: Text('Вы выбрали: $item')),
                  );
                },
              );
            }).toList(),
          ),
        ),
        actions: [
          TextButton(
            child: Text('Отмена'),
            onPressed: () {
              Navigator.of(context).pop();
            },
          ),
        ],
      );
    },
  );
}

Теперь в содержимом диалога будет список элементов, и нажатие на любой элемент покажет, какой элемент был выбран, и закроет диалог.
Пояснение:
- Мы используем виджет «AlertDialog» с заголовком и динамическим содержимым в виде списка.
- Для каждого элемента списка создается «ListTile», который реагирует на нажатие.
- После выбора элемента диалог закрывается с помощью «Navigator.of(context).pop()», а выбранный элемент отображается через «SnackBar».
- Также предусмотрена кнопка «Отмена», которая закрывает диалог.

2.3 Работа с TimePickerDialog

TimePickerDialog предоставляет пользовательский интерфейс для выбора времени, если вам нужно получить точное время от пользователя.
Изменим showDialog() следующим образом:

void showDialog(BuildContext context) async {
// Получаем текущее время
    TimeOfDay currentTime = TimeOfDay.now(); 
    TimeOfDay? pickedTime = await showTimePicker(
      context: context,
      initialTime: currentTime,
    );

    if (pickedTime != null) {
      // Форматируем строку времени
      String formattedTime = 
pickedTime.hour.toString().
padLeft(2, '0') + ':' + pickedTime.
minute.toString().padLeft(2, '0');
      // Выводим сообщение с выбранным временем
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text("Вы выбрали: $formattedTime")),
      );
    }}

В данном примере выводится диалог с выбранным текущим временем. Пользователь может выбрать собственное время и закрыть диалог. После этого будет выведено сообщение с введенным пользователем временем.

2.3 Работа с DatePickerDialog

DatePickerDialog предоставляет удобный способ для пользователей выбирать даты, и он широко используется в различных приложениях, где требуется работа с датами.
Изменим метод showDialog():

void showDialog (BuildContext context) async {
// Получаем текущую дату
    DateTime today = DateTime.now(); 
    DateTime? pickedDate = await showDatePicker(
      context: context,
      initialDate: today,
      firstDate: DateTime(2000), // Минимальная дата
      lastDate: DateTime(2101),  // Максимальная дата
    );

    if (pickedDate != null) {
      // Форматируем строку даты
      String formattedDate = 
"${pickedDate.day}/
 ${pickedDate.month}/
 ${pickedDate.year}";
      // Выводим сообщение с выбранной датой
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text("Вы выбрали: 
       $formattedDate")),
      );
    }
  }

При открытии диалога пользователю будет выведен календарь с выбранной сегодняшней датой. Пользователь может выбрать любую другую дату и закрыть диалог, после чего будет выведено сообщение с информацией какую дату он выбрал.

2.1 Общие сведения о виджетах

Виджеты – это что-то наподобие мини-приложений, расположенных на рабочем столе (Home). Они позволяют просмотреть какую-либо информацию из основных приложений, либо повлиять на поведение этих приложений. В качестве примера можно привести – прогноз погоды, текущее время, баланс какого-либо счета, список сообщений в различных мессенджерах, управление состоянием WiFi/3G/GPS/Bluetooth, яркость экрана и т.д. и т.п. В этой лабораторной сделаем простейший виджет, который отобразит статичный текст и будет изменять цвет своего фона при нажатии.

2.2 Создание простейшего виджета

Чтобы создать приложение на Flutter, которое добавляет виджет на рабочий стол (home screen) мобильного устройства (например, Android или iOS), вам потребуется использовать нативные функции платформы для создания виджетов. На данный момент Flutter не поддерживает создание виджетов для мобильных устройств напрямую, но вы можете использовать пакет, который интегрируется с нативными кодами.

 Шаги для создания виджета на Android

1. Создайте новый проект Flutter:

   flutter create widget_app
   cd widget_app
2. Добавьте необходимые зависимости:
   
Вам нужно добавить плагин для работы с виджетами. На данный момент популярным выбором является пакет «android_widget».

   В файле «pubspec.yaml» добавьте:

   dependencies:
     flutter:
       sdk: flutter
     android_widget: ^0.2.

   Затем выполните команду: flutter pub get

3. Создайте виджет:
   
Теперь создайте виджет, который будет отображаться на рабочем столе. В корне проекта создайте новую папку «android» и создайте там файл «MyWidget.java» со следующим содержимым:

      package com.example.widget_app;
   import android.appwidget.AppWidgetManager;
   import android.appwidget.AppWidgetProvider;
   import android.content.Context;
   import android.widget.RemoteViews;

   public class MyWidget extends AppWidgetProvider {
       @Override
       public void onUpdate(Context context, 
   AppWidgetManager appWidgetManager,
   int[] appWidgetIds) {
           for (int appWidgetId : appWidgetIds) {
               RemoteViews views = 
    new RemoteViews(context.getPackageName(),
        R.layout.widget_layout);
      // Обновление виджета, добавьте свои действия
      appWidgetManager.updateAppWidget(appWidgetId, views);
           }
       }
   }



4. Создайте XML макет для виджета:
   
В папке «android/app/src/main/res/layout» создайте файл «widget_layout.xml»:

   &lt;?xml version="1.0" encoding="utf-8"?&gt;
   &lt;RelativeLayout 
  xmlns:android="http://schemas.android.com/apk/res/android"
       android:layout_width="wrap_content"
       android:layout_height="wrap_content"&gt;

       &lt;TextView
           android:id="@+id/widget_text"
           android:layout_width="wrap_content"
           android:layout_height="wrap_content"
           android:text="Hello, Widget!"
           android:textSize="20sp"
           android:padding="16dp"
    android:background="@android:color/holo_blue_light"/&gt;
   &lt;/RelativeLayout&gt;

5. Зарегистрируйте виджет в манифесте:
   
В файле «AndroidManifest.xml» добавьте следующий код внутри тега «&lt;application&gt;»:

   &lt;receiver android:name=".MyWidget"&gt;
       &lt;intent-filter&gt;
           &lt;action android:name="android.appwidget.action.APPWIDGET_UPDATE" /&gt;
       &lt;/intent-filter&gt;

       &lt;meta-data
           android:name="android.appwidget.provider"
           android:resource="@xml/my_widget_info" /&gt;
   &lt;/receiver&gt;

6. Создайте файл конфигурации виджета:
   
В папке «android/app/src/main/res/xml» создайте файл «my_widget_info.xml»:

   &lt;?xml version="1.0" encoding="utf-8"?&gt;
   &lt;appwidget-provider xmlns:android="http://schemas.android.com/apk/res/android"&gt;
       &lt;initialLayout&gt;@layout/widget_layout&lt;/initialLayout&gt;
       &lt;updatePeriodMillis&gt;0&lt;/updatePeriodMillis&gt;
       &lt;appWidgetCategory&gt;home_screen&lt;/appWidgetCategory&gt;
   &lt;/appwidget-provider&gt;

7. Запустите приложение:

   После того как все настроено, запустите ваше приложение на устройстве Android. Теперь вы можете добавить виджет на рабочий стол вашего устройства Android:
1. Нажмите и удерживайте на пустом месте рабочего стола.
2. Выберите "Виджеты".
3. Найдите ваш виджет и перетащите его на рабочий стол.
Примечание
На данный момент создание виджетов для iOS значительно сложнее и требует использования нативного кода на Swift или Objective-C. Flutter не поддерживает создание виджетов для iOS из коробки. Если вам нужно создать виджет для iOS, придется использовать комбинацию Flutter и нативного кода.

2.1 Общие сведения об адаптерах

Адаптеры в Android – это важный инструмент для работы с данными и их отображения в различных виджетах, таких как списки (например, ListView, RecyclerView), спиннеры (выпадающие списки) и другие пользовательские интерфейсные элементы. Они играют критическую роль в преобразовании данных из их исходного формата в форму, пригодную для отображения пользователю. Адаптеры позволяют управлять данными и их отображением в пользовательском интерфейсе более эффективно и гибко. Они являются важной составной частью создания Android-приложений, особенно при работе с списками и другими виджетами, отображающими данные.
В Flutter адаптер часто используется в контексте работы с различными источниками данных, например, для преобразования данных между источниками и отображения их в UI-компонентах (например, в списках). Понятие адаптера хорошо знакомо в разработке Android (например, ListAdapter, RecyclerView.Adapter), но в Flutter нет прямого аналога таких классов, так как архитектура Flutter работает несколько иначе.

2.2 Создание приложения со списком с помощью ListView.builder

Это оптимальный способ работы с большими списками данных, так как он не создает все элементы списка сразу, а генерирует их по мере необходимости.

 Icons.local_drink),

  void incrementCartQuantity(Product product) {
    setState(() {
      if (product.availableQuantity &gt; 0) {
        product.cartQuantity += 1;
        product.availableQuantity -= 1;
      }

  }

  // Метод уменьшения количества товара в корзине

      if (product.cartQuantity &gt; 0) {
        product.cartQuantity -= 1;

      }
    });
  }

Лабораторная работа №2.4 – Future как средство выполнения фоновых задач

1 Цель работы

2 Порядок выполнения работы 

2.1 Общие сведения об Future

В языке программирования Dart объект типа Future представляет результат асинхронной операции, которая завершится в будущем. Это одна из ключевых концепций при работе с асинхронным кодом в Dart, и она используется для выполнения операций, которые могут занять неопределённое количество времени (например, HTTP-запросы, чтение файлов и т.д.), не блокируя основной поток выполнения программы.
Future – это объект, который содержит или будет содержать результат асинхронной операции. Операция может завершиться успехом (с возвращением данных) или с ошибкой. Когда асинхронная операция запускается, она возвращает Future, который «ожидает» завершения операции. Чтобы дождаться завершения Future и получить результат, используется ключевое слово await:

Future&lt;String&gt; fetchData() async {
  // симуляция длительной операции, например, сетевой запрос
  await Future.delayed(Duration(seconds: 2));
  return 'Данные загружены';
}

void main() async {
  print('Загрузка...');
  String result = await fetchData();
  print(result);
}

В этом примере await приостанавливает выполнение функции до получения результата от асинхронной операции. Альтернативный способ работы с Future – это использование метода then() для обработки результата:

Future&lt;String&gt; fetchData() {
  return Future.delayed(Duration(seconds: 2), () =&gt; 'Данные 
    загружены');
}

void main() {
  print('Загрузка...');
  fetchData().then((result) {
    print(result);
  }).catchError((error) {
    print('Произошла ошибка: $error');
  });
}

Ключевые слова async и await делают код асинхронных операций более читабельным и понятным, чем использование методов then, catchError для обработки асинхронных результатов.
async – используется для пометки функции как асинхронной. Это значит, что она может содержать операции, которые будут выполняться асинхронно. Функция, объявленная как async, всегда возвращает объект типа Future, даже если возвращаемый тип явно не указан.
await – используется для приостановки выполнения программы до тех пор, пока асинхронная операция (объект типа Future) не завершится. Когда операция завершится, выполнение продолжится с результатом этой операции.
Чтобы обработать возможные ошибки в асинхронном коде, можно использовать блок try-catch в сочетании с await:

void main() {
  try {
// Ожидание результата Future
    String data = await fetchData(); 
    print(data); // Вывод данных, когда Future завершён
  } catch (e) {
    print('Ошибка: $e');
  }
}

whenComplete – метод, который вызывается после завершения, вне зависимости от того, было это успешное выполнение или ошибка.

Future&lt;String&gt; fetchData() async {
  await Future.delayed(Duration(seconds: 2));
  return 'Данные загружены';
}

void main() async {
  print('Загрузка...');

  // Используем whenComplete для 
  //выполнения действия после завершения
  String result = await fetchData().whenComplete(() {
    print('Выполнено, независимо от результата.');
  });

  print(result);
}

wait – метод, который позволяет ожидать завершения нескольких Future одновременно.

Future&lt;void&gt; loadData() async {
  await Future.wait([fetchData1(),
  fetchData2(), fetchData3()]);
  print('Все данные загружены');
}

Метод loadData асинхронно загружает данные из трёх источников одновременно и выводит сообщение о завершении после их загрузки.

2.2 Создание простейшего приложения с использованием Future
 
Код представляет собой Flutter-приложение с простым асинхронным процессом. Приложение состоит из главной страницы, которая отображает кнопку для загрузки данных, индикатор загрузки во время выполнения задачи, и сообщение с результатом после завершения загрузки.

import 'package:flutter/material.dart';
void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: 
       Colors.deepPurple),
        useMaterial3: true,
      ),
      home: const AsyncExamplePage(),
    );
  }
}

class AsyncExamplePage extends StatefulWidget {
  const AsyncExamplePage({super.key});

  @override
  State&lt;AsyncExamplePage&gt; createState() =&gt; 
 _AsyncExamplePageState();
}

class _AsyncExamplePageState extends 
State&lt;AsyncExamplePage&gt; {
  // Переменная для хранения данных
  String? _data;
  bool _isLoading = false;

  // Метод для асинхронной загрузки данных
  Future&lt;void&gt; _loadData() async {
    setState(() {
      _isLoading = true; // Включаем индикатор загрузки
    });

// Эмуляция запроса
    await Future.delayed(const Duration(seconds: 3)); 
// Устанавливаем данные
    setState(() {
      _data = 'Данные успешно загружены!'; 
      _isLoading = false; // Отключаем индикатор загрузки
    });
  }

  // Метод для отображения интерфейса 
//в зависимости от  состояния
  Widget _buildBody() {
    // Показать индикатор, если идет загрузка
    if (_isLoading) {
      return const CircularProgressIndicator(); 
    } else if (_data != null) {
      return Text(
        _data!,
        style: const TextStyle(fontSize: 20),
      ); // Показать текст, если данные загружены
    } else {
      return const Text(
        'Нажмите на кнопку для загрузки данных.',
        style: TextStyle(fontSize: 18),
      ); // Сообщение перед загрузкой
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        backgroundColor: 
Theme.of(context).colorScheme.inversePrimary,
        title: const Text('Асинхронный пример'),
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
   // Используем метод для отображения контента
            _buildBody(), 
            const SizedBox(height: 20), 
            ElevatedButton(
// Запуск асинхронной задачи
              onPressed: _loadData, 
              child: const Text('Загрузить данные'),
            ),
          ],
        ),
      ),
    );
  }
}

Описание структуры приложения:
main – это точка входа в приложение. Здесь вызывается метод runApp, который запускает Flutter-приложение и отображает виджет MyApp;
MyApp – это виджет является корнем приложения;
AsyncExamplePage – это stateful виджет (тип виджета, который может изменяться в процессе работы – в данном случае, индикатор загрузки, отображение результата), так как его состояние изменяется (например, когда данные загружаются). Виджет отслеживает, загружаются ли данные или уже загружены;
_AsyncExamplePageState – это класс состояния для AsyncExamplePage. В нём реализована логика асинхронной загрузки данных и их отображения;
_loadData – метод для асинхронной загрузки данных;
_buildBody – метод для построения интерфейса. void _initStreams() {
    _durationSubscription = 
   player.onDurationChanged.
        listen((duration) {
      setState(() =&gt; _duration = duration);
    });

        player.onPlayerStateChanged.listen((state) {
      setState(() {
        _playerState = state;
      });
    });
  }

  Future&lt;void&gt; _play() async {
    await player.resume();
    setState(() =&gt; _playerState = PlayerState.playing);
  }

  Future&lt;void&gt; _pause() async {
    await player.pause();
    setState(() =&gt; _playerState = PlayerState.paused);
  }

  Future&lt;void&gt; _stop() async {
    await player.stop();
    setState(() {
      _playerState = PlayerState.stopped;
      _position = Duration.zero;
    });

Этот код представляет собой часть реализации аудиоплеера в Flutter/Dart. Он использует подписки на различные события, такие как изменение продолжительности, позиции и состояния воспроизведения. Функции «_play», «_pause» и «_stop» управляют воспроизведением аудиоплеера, меняя его состояние и обновляя пользовательский интерфейс.

 Описание функций и подписок:

1. _initStreams – инициализирует потоки событий и подписки на них:
   - _durationSubscription – подписка на изменения продолжительности аудио («onDurationChanged»). Когда продолжительность изменяется, обновляется переменная «_duration».
   - _positionSubscription – подписка на изменения позиции воспроизведения («onPositionChanged»). При изменении позиции обновляется переменная «_position».
   - _playerCompleteSubscription – подписка на событие завершения воспроизведения («onPlayerComplete»). Когда воспроизведение заканчивается, состояние плеера изменяется на «stopped», а позиция сбрасывается на ноль.
   - _playerStateChangeSubscription – подписка на изменения состояния плеера («onPlayerStateChanged»). При изменении состояния обновляется переменная «_playerState».
2. _play – запускает воспроизведение аудио, вызывая метод «resume» у объекта «player». После этого обновляется состояние плеера на «playing».
3. _pause – ставит воспроизведение на паузу, вызывая метод «pause». Состояние обновляется на «paused».
4. _stop – останавливает воспроизведение, вызывая метод «stop». После остановки состояние меняется на «stopped», а позиция сбрасывается на ноль.

Разберем каждый метод этого класса.
Метод initState():
Описание: этот метод вызывается при инициализации состояния виджета. В нем настраивается слушатель для текстового контроллера _fileExtensionController, чтобы отслеживать изменения текста в поле ввода расширений файлов. Это позволяет обновлять переменную _extension, которая хранит расширение выбранного файла.
Метод _pickFiles():
Описание: этот метод открывает диалоговое окно для выбора файлов. В нем устанавливаются различные параметры выбора файлов, такие как возможность выбора нескольких файлов, тип файлов (например, изображений, документов и т.д.), начальная директория и заголовок окна диалога. После того как пользователь выбрал файлы, информация о файлах сохраняется, и интерфейс обновляется с отображением выбранных файлов.
Параметры:
compressionQuality: (опционально) Качество сжатия файлов, по умолчанию установлено на 30. Это влияет на размер выбранных файлов;
type: Тип выбираемых файлов (например, FileType.image, FileType.any). Это указывает, какие файлы могут быть выбраны;
allowMultiple: Логическое значение, которое указывает, разрешено ли выбирать несколько файлов. Если значение true, можно выбрать несколько файлов, иначе – только один;
onFileLoading: Колбэк, который вызывается при загрузке файлов. Он может использоваться для отображения состояния загрузки;
allowedExtensions: (опционально) Список разрешенных расширений файлов, которые могут быть выбраны (например, ['jpg', 'png']).
dialogTitle: Заголовок диалогового окна;
initialDirectory: Начальная директория, в которой откроется диалог;
lockParentWindow: Логическое значение, указывающее, блокируется ли родительское окно во время выбора файла.
Метод _clearCachedFiles():
Описание: этот метод очищает кэш временных файлов, связанных с операциями выбора файлов. Он вызывает метод clearTemporaryFiles() из пакета file_picker, который удаляет временные файлы, созданные при предыдущих выборах. После выполнения операции в интерфейсе показывается уведомление (Snackbar) с результатом – успешно или неудачно.
Метод selectFolder():
Описание: этот метод открывает диалоговое окно для выбора папки. Когда пользователь выбирает папку, путь к ней сохраняется в переменной _directoryPath, и отображается в интерфейсе. Если пользователь отменяет выбор, устанавливается флаг _userAborted, и в интерфейсе показывается соответствующее сообщение.
Параметры:
dialogTitle: Заголовок диалога выбора папки;
initialDirectory: Начальная директория, в которой откроется диалог выбора папки;
lockParentWindow: Логическое значение, указывающее, блокируется ли родительское окно во время выбора папки.
Метод _saveFile():
Описание: этот метод открывает диалоговое окно для сохранения файла. Пользователь может выбрать место для сохранения и задать имя файла. Когда пользователь сохраняет файл, его путь и имя сохраняются в переменной _saveAsFileName, и обновляется интерфейс, чтобы показать информацию о сохраненном файле.
Параметры:
allowedExtensions: (опционально) Список разрешенных расширений файлов для сохранения, например, ['jpg', 'png'];
type: Тип файла, который можно сохранить (например, FileType.image);
dialogTitle: Заголовок диалога для сохранения файла;
fileName: Имя файла по умолчанию, которое будет предложено пользователю;
initialDirectory: Начальная директория, в которой откроется диалог для сохранения файла;
lockParentWindow: Логическое значение, указывающее, блокируется ли родительское окно во время сохранения файла.
Метод logException(String message):
Описание: этот метод логирует исключения и ошибки. Если в процессе выполнения возникает ошибка, она выводится в консоль и отображается в интерфейсе через уведомление (Snackbar) с сообщением об ошибке.
Метод _resetState():
Описание: этот метод сбрасывает все состояния, связанные с операциями выбора файлов или папок. После его вызова очищаются все переменные, которые содержат информацию о выбранных файлах, пути и имени файла. Также включает индикатор загрузки, который сигнализирует, что система готова к следующей операции.
Методы класса FilePickerDemo используются для работы с файловой системой, позволяя пользователю выбирать файлы, папки, а также сохранять файлы на устройстве. Каждый метод отвечает за конкретную операцию (например, выбор файла, очистка кэша или сохранение файла), и в зависимости от результата взаимодействия с пользователем обновляет состояние и интерфейс приложения.

2 Порядок выполнения работы

2.1 Общие сведения о SQLite

SQLite – это встроенная система управления базами данных, которая широко используется в разработке приложений для Android. Она предоставляет легковесное и эффективное средство для работы с данными в приложениях для мобильных устройств.
Использование SQLite в Android – это важная часть разработки мобильных приложений, так как это позволяет хранить и управлять данными, необходимыми для приложения.

2.2 Работа с SQLite.

Откройте файл pubspec.yaml и добавьте зависимость sqflite для работы с SQLite, а также path для указания пути к базе данных.

dependencies:
  flutter:
    sdk: flutter
  sqflite: ^2.0.0+4
  path: ^1.8.0

Теперь создадим файл для работы с SQLite. В проекте создадим файл lib/db_service.dart, в котором будет реализована вся логика работы с базой данных.

import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';

class DBService {
  static final DBService _instance = DBService._internal();
  factory DBService() =&gt; _instance;

  DBService._internal();

  Database? _database;

  Future&lt;Database&gt; get database async {
    if (_database != null) return _database!;
    _database = await _initDatabase();
    return _database!;
  }

  Future&lt;Database&gt; _initDatabase() async {
    String path = join(await getDatabasesPath(), 'MyDatabase.db');
    return await openDatabase(
      path,
      version: 1,
      onCreate: (db, version) async {
        await db.execute(
          'CREATE TABLE IF NOT EXISTS MyTable (
   id INTEGER PRIMARY KEY AUTOINCREMENT, 
   name TEXT)',
        );
      },
    );
  }

  // Добавление новой записи
  Future&lt;int&gt; addRecord(String name) async {
    final db = await database;
    return await db.insert(
      'MyTable',
      {'name': name},
    );
  }

// Обновление записи
  Future&lt;void&gt; updateRecord(int id, String newName) async {
    final db = await database;
    await db.update(
      'MyTable',
      {'name': newName},
      where: 'id = ?',
      whereArgs: [id],
    );
  }

  // Удаление записи
  Future&lt;int&gt; deleteRecord(int id) async {
    final db = await database;
    return await db.delete(
      'MyTable',
      where: 'id = ?',
      whereArgs: [id],
    );
  }

// Выборка всех записей без сортировки
  Future&lt;List&lt;Map&lt;String, dynamic&gt;&gt;&gt; getAllRecords() async {
    final db = await database;
    return await db.query('MyTable');
  }

// Выборка с сортировкой по имени
  Future&lt;List&lt;Map&lt;String, dynamic&gt;&gt;&gt; getSortedRecords() async {
    final db = await database;
    return await db.query(
      'MyTable',
      orderBy: 'name DESC', // Сортировка по убыванию
    );
  }
}

Описание:
getAllRecords: Этот метод возвращает все записи из таблицы MyTable, без применения сортировки. database: Это асинхронная переменная, которая возвращает экземпляр базы данных, либо создаёт новый, если он не существует. db.query('MyTable'): Это SQL запрос, который извлекает все записи из таблицы MyTable без сортировки. Метод query возвращает результат в виде списка карт (List of Map), где каждая карта представляет собой строку из таблицы, а ключи карты – это имена столбцов. 
getSortedRecords: этот метод возвращает все записи из таблицы MyTable, отсортированные по полю name по убыванию. db.query('MyTable', orderBy: 'name DESC'): В этом запросе мы добавляем параметр orderBy: 'name DESC', который указывает на то, что записи должны быть отсортированы по столбцу name в порядке убывания (по убыванию). name DESC означает "по убыванию". Если бы мы использовали ASC (по возрастанию), результат был бы отсортирован по имени от А до Я.
addRecord: Этот метод добавляет новую запись в таблицу MyTable с именем, которое передается как параметр. db.insert('MyTable', {'name': name}): Этот метод вставляет новую запись в таблицу MyTable. Мы передаем карту, где ключом является name, а значением – переданное имя, которое нужно добавить в таблицу. Так как столбец id является автоинкрементом (он увеличивается автоматически), нам не нужно указывать значение для id – оно будет присвоено базе данных.
updateRecord: Этот метод обновляет имя записи по указанному ID. db.update(): Этот метод обновляет существующую запись в таблице. Мы передаем имя таблицы, обновляемые данные (в данном случае только поле name) и условие для обновления. where: 'id = ?': Мы указываем, что обновление должно произойти только для записи с определенным id. Это условие идентифицирует запись, которую нужно обновить. whereArgs: [id]: это значение id передается в запрос для выполнения обновления конкретной записи.
deleteRecord: этот метод удаляет запись по ID. db.delete(): Этот метод удаляет запись из таблицы MyTable. Мы передаем условие, по которому будет найдено, что именно нужно удалить. where: 'id = ?': Условие указывает, что необходимо удалить запись с определенным id. whereArgs: [id]: Это значение id передается в запрос для выполнения удаления записи.

2.3 Создание интерфейса пользователя

Теперь создадим экран с кнопками для добавления, редактирования, удаления записей, а также для отображения записей с сортировкой и без. В проекте создадим файл lib/home_screen.dart, в котором будет реализована вся логика работы с базой данных

import 'package:flutter/material.dart';
import 'db_service.dart';

class HomeScreen extends StatefulWidget {
  const HomeScreen({super.key});

  @override
  State&lt;HomeScreen&gt; createState() =&gt; _HomeScreenState();
}

class _HomeScreenState extends State&lt;HomeScreen&gt; {
  final DBService dbService = DBService();
  List&lt;Map&lt;String, dynamic&gt;&gt; records = [];

  final TextEditingController _nameController = 
 TextEditingController();

  @override
  void initState() {
    super.initState();
    _fetchRecords();
  }

  // Получение всех записей
  Future&lt;void&gt; _fetchRecords() async {
    final data = await dbService.getAllRecords();
    setState(() {
      records = data;
    });
  }

  // Сортировка по имени
  Future&lt;void&gt; _sortRecords() async {
    final data = await dbService.getSortedRecords();
    setState(() {
      records = data; // Обновляем записи
    });
  }

  // Добавление записи
  Future&lt;void&gt; _addRecord() async {
    if (_nameController.text.isNotEmpty) {
      await dbService.addRecord(_nameController.text);
      _nameController.clear();
      _fetchRecords();
    }
  }

// Редактирование записи
  Future&lt;void&gt; _updateRecord(int id, String currentName) async {
    // Контроллер для нового имени
    final TextEditingController _editController =
        TextEditingController(text: currentName);

    // Показываем диалоговое окно для редактирования
    showDialog(
      context: context,
      builder: (context) {
        return AlertDialog(
          title: const Text('Редактировать запись'),
          content: TextField(
            controller: _editController,
            decoration: const InputDecoration(
              labelText: 'Введите новое имя',
              border: OutlineInputBorder(),
            ),
          ),
          actions: [
            TextButton(
              onPressed: () {
                Navigator.of(context).pop(); // Закрыть диалог
              },
              child: const Text('Отменить'),
            ),
            TextButton(
              onPressed: () async {
                // Обновляем запись, если введено новое имя
                if (_editController.text.isNotEmpty) {
                  await dbService.updateRecord(id, 
   _editController.text);
   // Обновляем список после изменения
                  _fetchRecords();
                  Navigator.of(context).pop(); // Закрыть диалог
                }
              },
              child: const Text('Сохранить'),
            ),
          ],
        );
      },
    );
  }

  // Удаление записи
  Future&lt;void&gt; _deleteRecord(int id) async {
    await dbService.deleteRecord(id);
    _fetchRecords();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('SQLite Demo')),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(8.0),
            child: TextField(
              controller: _nameController,
              decoration: const InputDecoration(
                labelText: 'Введите имя',
                border: OutlineInputBorder(),
              ),
            ),
          ),
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceEvenly,
            children: [
              ElevatedButton(
                onPressed: _addRecord,
                child: const Text('Добавить запись'),
              ),
              ElevatedButton(
                onPressed: _sortRecords,
                child: const Text('Сортировка по имени'),
              ),
            ],
          ),
          Expanded(
            child: ListView.builder(
              itemCount: records.length,
              itemBuilder: (context, index) {
                final record = records[index];
                return ListTile(
                  title: Text(record['name']),
                  trailing: Row(
                    mainAxisSize: MainAxisSize.min,
                    children: [
                      IconButton(
                        icon: Icon(Icons.edit),
    // Передаем ID и имя
                        onPressed: () =&gt; _updateRecord(
                            record['id'], record['name']), 
                      ),
                      IconButton(
                        icon: Icon(Icons.delete),
                        onPressed: () =&gt; 
  _deleteRecord(record['id']),
                      ),
                    ],
                  ),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

2.1 Общие сведения о сервисах

Сервисы представляют собой особую организацию приложения. В отличие от activity они не требуют наличия визуального интерфейса. Сервисы играют важную роль в разработке мобильных приложений, предоставляя возможность выполнения фоновых задач и обеспечивая независимость от основного пользовательского интерфейса. Сервисы позволяют приложениям выполнять долгосрочные операции без вмешательства пользователя, взаимодействовать с аппаратными ресурсами устройства и предоставлять различные функции, которые доступны вне зависимости от текущей активности приложения.
В контексте мобильной разработки на платформе Android, сервисы представляют собой важный инструмент для создания приложений, которые способны выполнять задачи в фоновом режиме, даже когда пользователь не активно взаимодействует с приложением. Это позволяет реализовать разнообразные функциональности, такие как фоновая загрузка данных, обработка уведомлений, аудио- и видео-проигрывание, а также многие другие сценарии использования.

2.2 Создание сервиса

Перед созданием сервиса необходимо добавить библиотеку в проект. provider – библиотека для управления состоянием. Она позволяет предоставлять доступ к сервису RandomNumberService из любого места в приложении. Добавьте её в свой проект командой flutter pub add provider.
Создайте файл random_number_service.dart в папке lib.
В созданном классе, опишите ваш сервис следующим образом:

import 'dart:math';

class RandomNumberService {
  final _random = Random();

  /// Генерирует случайное число от [min] до [max] включительно.
  int generateRandomNumber(int min, int max) {
    return min + _random.nextInt(max - min + 1);
  }
}

Сервис использует класс Random из библиотеки dart:math.
Метод generateRandomNumber: параметры min и max определяют диапазон случайного числа. Возвращает случайное число между min и max.
Назначение: сервис отделяет логику генерации числа от пользовательского интерфейса, что упрощает тестирование и поддержку.

MyApp: создаёт корневую структуру приложения. Устанавливает RandomNumberPage как начальный экран приложения.
